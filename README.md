# Aswin Sivadas - Modern Developer Portfolio

A stunning, highly interactive personal portfolio built with modern web technologies. This portfolio is designed to showcase full-stack development skills, projects, and experiences with an emphasis on premium aesthetics, 3D animations, and buttery smooth user experiences.

- **Frontend Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Vanilla CSS Modules
- **Animations:** Framer Motion & GSAP
- **3D & WebGL:** Three.js & React Three Fiber (@react-three/fiber)
- **Smooth Scrolling:** Lenis (Studio Freight)
- **Icons:** Lucide React & React Icons
- **UI Components:** Customized React Bits components (Silk, Lightfall, ProfileCard, ScrollStack, SplitText)

## ✨ Key Features

- **Immersive Loading Screen:** Custom `MacStartup` sequence with a dynamic, WebGL-powered `Silk` background effect.
- **Hero Section:** Interactive spotlight cursor effects, 3D floating avatars, and GSAP-powered `SplitText` cascading typography.
- **Services Stack:** A unique vertical `ScrollStack` interface using glassmorphism cards that beautifully pile and fade as you scroll down.
- **Interactive About Section:** Featuring a responsive 3D tilting `ProfileCard` with micro-interactions and custom gradient glows.
- **Smooth Scrolling:** Native-feeling inertia scroll powered by Lenis, perfectly synchronized with ScrollTrigger animations.
- **Theme Support:** Dynamic Dark and Light mode transitions via a custom `ThemeContext`.
- **Responsive Design:** Fully fluid typography and scaling logic that looks flawless on mobile, tablet, and ultra-wide displays.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aswinsivadas-tech/Modern-Portfolio.git
   cd Modern-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `/src/components/sections` - Core page sections (Home, About, Services, Projects, etc.)
- `/src/components/ui` - Reusable, highly interactive UI components (ScrollStack, Silk, ProfileCard, etc.)
- `/src/components/animations` - Complex animation wrappers and loading screens
- `/src/context` - React contexts (ThemeContext)
- `/src/lib` - Utility functions and helpers
- `/public/assets` - Static images, 3D models, and CV files
